What to take from shadcn, and from Clinova

A component-by-component read of shadcn/ui against what the dashboard actually does today, a measured look at the Clinova hospital demo, and three directions to choose between. Every shadcn value here was read from its source repository, not recalled.

Recommendation

Build on shadcn's Nova style with its warm olive neutrals, brand green and IBM Plex Sans, and borrow Clinova's tile anatomy: icon chip, sparkline, trend, denominator. The reference you liked

Clinova works because it is calm, and it is calm on purpose

I measured the page rather than describing an impression. Nothing in it is loud: one hue, one border weight, no shadows on cards, and every number framed by a label, a trend and a comparison. It is built on Tailwind with the same token names shadcn uses, which is why almost all of it transfers.

A warm ground, not a white one

bg oklch(98.5% .004 90) · sidebar 96.5% · border 90% .006 90

The neutrals lean faintly toward stone. It reads as paper under good light rather than a screen.

For TF Monitorshadcn's olive base colour is the nearest built-in: same low chroma, hue 106 against Clinova's 90.

One clinical hue, used sparingly

primary oklch(55% .09 195) · active nav 93% .02 195

Teal appears on the primary button, the active nav item, icon chips and the main chart series. Everything else is neutral.

For TF Monitorbrand green #08684E sits at hue 168, next to shadcn's emerald at 166. Start from emerald and override its primary with the exact brand value.

Cards separated by a border, not lifted

rounded-xl 12px · 1px border · no shadow · p-4 16px · gap-3

No card floats above another, so the eye moves across the grid instead of stopping at elevation.

For TF Monitorthis is almost exactly Nova's card: 16px spacing, a 1px ring, no shadow.

Tiles with an anatomy

36px tinted icon chip · sparkline · 24px/700 value · trend · "vs last week"

Each tile answers three questions at a glance: what is this, what is it now, and which way is it moving.

For TF Monitorsparklines can come from the quarterly progress already in /api/overview. No new endpoint.

Navigation that shows where you are

260px sidebar · grouped, collapsible sections · tinted active pill · user card in footer

Grouped sections collapse, the active page is a soft tint rather than a bar, and the account sits at the bottom where it is out of the way.

For TF Monitorshadcn Sidebar does all of this, plus an icon-only collapsed width of 3rem.

A header that stays, and gets out of the way

sticky · h-16 · 80% translucent background · border-b · ⌘K search

Search is the first control, with its shortcut shown. The header never covers content because it is translucent.

For TF MonitorCommand + Kbd for a palette that jumps to a page, a facility or an LGA.

What does not carry over directly

"vs last week" is the wrong comparison. TF Monitor updates from a bi-weekly line list, so a trend means "vs the previous line list", and the Line list changes page already computes it.

Recent quarters are still maturing. A sparkline that ends on an unfinished quarter shows a false collapse. The last point needs the same dashed, provisional treatment the re-suppression trend already uses.

Its threshold bars are colour alone. Clinova's red, amber and teal department bars carry no label. In TF Monitor, status must always come with an icon and a word.

It is a paid template. Clinova is a DashboardPack product. We take its qualities, not its markup, name or layout.

shadcn/ui, September 2026

shadcn is no longer one look. It ships eight.

A shadcn project now picks a style that changes component geometry and density, not just colour. Base UI replaced Radix as the default component library on 2 July 2026; Radix remains fully supported. Values below are read from each style's stylesheet, in pixels at shadcn's default radius.

Why Nova. TF Monitor carries seven headline tiles, a filter bar with ten controls and tables of up to several hundred rows. Nova and Rhea are the two styles that tighten card and control spacing while keeping 14px text; Nova does it with 14px corners, a hairline edge and no shadow. Lyra and Mira are denser still, but drop card text to 12px, too small for programme staff reading narratives and worklists on a laptop. Luma, Maia and Sera spend space the dashboard does not have. Rhea is the one real alternative: compact like Nova, but soft and rounded.

Also confirmed: IBM Plex Sans is one of shadcn's built-in font choices, so the brand face needs no workaround. IBM Plex Mono is not, and stays self-hosted as it is now. Every component this review recommends exists in both Base UI and Radix, except Toast, which is Base UI only; Radix projects use Sonner instead.

If we take Option 1

The order to build it in

The React app keeps running beside the live dashboard at /app, as it does now. Each step leaves something usable, and nothing reaches state teams until a page matches the numbers on the current one.

  1. Foundation

    Add Tailwind v4 and Base UI with the Nova style, olive base and brand-green primary. Self-host IBM Plex as now, so the no-external-requests rule survives.

  2. Frame

    Sidebar with grouped sections and the line-list footer; a sticky translucent header with the account menu. Retire the ported rail CSS.

  3. Filter bar

    Combobox for Facility, both LGAs and Month; Toggle Group for Sex. The existing cascade rules and their tests carry over unchanged.

  4. Overview in the new anatomy

    Card-based tiles with icon chips, quarterly sparklines (last quarter provisional), Hover Card definitions, Empty and Alert states.

  5. Worklists

    Data Table for the intervention worklist, facility league and DTC lists, with row selection feeding export and a Sheet for episode detail.

  6. Remaining pages, then charts

    Port page by page. Revisit Chart.js versus Recharts only once every page renders, so no number moves during the migration.

Decisions for you

Three calls to make before building

Which direction

Option 1 is closest to Clinova and to how the dashboard is used. If Rhea's softness appeals, it can be tried on one page before committing.

Base UI or Radix

Base UI is shadcn's default since July 2026 and the only one with the new Toast. Radix is equally supported. I would start on Base UI.

Sparklines on tiles

They add the "which way is it moving" Clinova does well, but only with the provisional last quarter marked. Say if you would rather keep tiles to a number and a denominator.
